We built this site from one written brief. React and viem, static files. No backend, database, or server. We read contracts live in the browser. PixelArt draws the art. We use no metadata API or image host. Home shows live supply and checks any address's slots without a wallet. Gallery reads every minted token URI, filters traits, and lets anyone batch reveal another token. About explains the reveal: each mint commits to the next block before its hash exists. At this reading, one thousand fifty-three were minted.
